# iOS 27 영감형 PIKO 설문 디자인

## 목표

설문 문항, 단계 전환, 응답 저장과 이벤트 기록은 그대로 보존한다. 모든 화면의 시각 언어만 Apple iOS/iPadOS 27 UI Kit의 Liquid Glass 방향을 참고한 반응형 웹 디자인으로 바꾼다. Apple의 로고, SF Symbols, 정적 에셋과 네이티브 화면을 그대로 복제하지 않는다.

## 디자인 원칙

- 밝은 청회색 그라데이션과 은은한 색 번짐을 전체 배경으로 사용한다.
- 헤더, 카드, 입력 영역은 반투명 흰색 표면과 배경 흐림으로 계층을 만든다.
- 시스템 글꼴(`-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, sans-serif)을 우선 사용한다.
- 파랑은 주요 행동과 선택 상태, 초록은 여유도·성공·히트맵 강도에만 사용한다.
- 선택 상태는 배경색뿐 아니라 테두리와 체크 표시로 구별하고, 모든 인터랙션에 키보드 포커스 표시를 제공한다.

## 공통 컴포넌트

### 앱 셸과 상단바

- `app-shell`은 넓은 화면에서 읽기 편한 최대 폭을 유지하며, 모바일에서는 좌우 여백을 줄인다.
- 상단바는 반투명 배경과 흐림 효과가 있는 고정 헤더로 구성한다.
- 진행률은 얇은 파란 캡슐 바와 현재 단계 표기(`3 / 6`)를 함께 보여준다.

### 카드와 입력 컨트롤

- 카드, 포스터 정보 영역, 응답 요약은 16~24px 반경의 유리 표면으로 통일한다.
- 기본 버튼은 파란 채움, 보조 버튼은 반투명 표면, 비활성 버튼은 낮은 대비로 표현한다.
- 선택 칩, 카드, 점수 버튼은 선택 시 파란 테두리와 체크 표식을 보인다.
- 입력칸과 텍스트 영역은 밝은 반투명 배경, 부드러운 테두리, 선명한 포커스 링을 사용한다.

## 화면별 적용

### 시작, 프로필, 판단

- 기존의 2열 정보 구조와 문항 순서는 보존한다.
- 안내 영역, 입력 폼, 작품 선택 카드를 유리 카드로 바꾼다.
- 작품 포스터의 색상 데이터와 선택 로직은 유지한다.

### 캘린더 비교

- 주간 히트맵은 밝은 유리 카드에 유지한다.
- 낮음~높음 단계는 초록 팔레트를 유지하며, 선택 날짜는 테두리로 강조한다.
- 시안 A/B/C의 비교와 기존 선택·이벤트 기록 방식은 변경하지 않는다.

### 컬렉션과 홈 프로토타입

- 컬렉션 카드, 필터, 작품 카드, 추천 사유를 밝은 iOS 영감형 표면으로 일관되게 표현한다.
- 홈 프로토타입은 설문 속 예시 화면으로서 동일한 디자인 시스템을 사용하되, 데이터와 상호작용은 현행 그대로 둔다.

### 검토와 완료

- 응답 요약은 구분된 유리 카드로 제공한다.
- 완료 화면은 파란 체크 원형 마크와 응답 식별자를 유지한다.

## 반응형과 접근성

- 720px 이하에서는 다열 레이아웃을 한 열로 전환한다.
- 상단바 보조 문구는 좁은 화면에서 숨길 수 있으나 브랜드와 진행 상태는 항상 보인다.
- 색상만으로 상태를 전달하지 않으며, `:focus-visible` 포커스 링과 읽을 수 있는 대비를 유지한다.
- 기존 ARIA 레이블과 버튼 semantics는 보존한다.

## 구현 경계와 검증

- 변경 대상은 스타일시트와 화면의 표현용 마크업뿐이다. `SurveySession`, repository, 질문 ID, 이벤트 이름 및 제출 흐름은 수정하지 않는다.
- 기존 테스트는 유지하고, 선택 상태/핵심 화면 표현에 대한 회귀 테스트를 보강한다.
- 구현 후 `npm test`, `npm run lint`, `npm run build`를 모두 실행한다.
